# CRM Logistics

MVP системы для грузоперевозок.

## Цель
Сначала запускаем Telegram-бота с базой данных и общей бизнес-логикой. Затем на этой же базе и backend строим Telegram Mini App и при необходимости отдельное приложение.

## Состав проекта
- `backend/` — API, бизнес-логика, расчёты
- `bot/` — Telegram bot интерфейс
- `db/` — схема базы данных, миграции, сиды
- `frontend/` — будущий Mini App
- `shared/` — общие типы, схемы, утилиты
- `docs/` — ТЗ, архитектура, заметки

## MVP v1
- учёт машин
- учёт поездок
- учёт расходов
- статус денег: отданы / не отданы
- сводка по выручке
- аналитика по периоду
- подготовка к PDF-отчётам

## Технологический курс
- backend: Node.js + TypeScript
- bot: Telegram Bot API
- database: PostgreSQL
- ORM: Prisma
- validation: Zod

## Порядок разработки
1. База данных и сущности
2. Backend-модуль расчётов
3. Telegram bot MVP
4. Аналитика
5. PDF
6. Mini App
