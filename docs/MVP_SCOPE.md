# MVP Scope

## In scope
- Создание и хранение машин
- Создание поездок с полями:
  - дата
  - машина
  - адрес / направление
  - сумма
  - комментарий
  - статус денег отданы / не отданы
- Создание расходов с полями:
  - дата
  - машина
  - категория
  - сумма
  - комментарий
- Базовые категории расходов:
  - пробег
  - зарплата
  - топливо
  - ремонт
- Пользовательские категории расходов
- Главная сводка за месяц
- Аналитика по периоду
- Основа для PDF-отчётов

## Out of scope for first build
- Premium
- Платежи
- Донаты
- Полный UI Mini App
- Сложные права доступа

## First user scenarios
1. Добавить машину
2. Добавить поездку
3. Добавить расход
4. Посмотреть сводку по машине
5. Посмотреть аналитику за период
6. Изменить статус денег по поездке
